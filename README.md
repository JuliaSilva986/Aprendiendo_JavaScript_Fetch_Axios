# 🚀 Consumo de API con Fetch y Axios

Mini proyecto desarrollado en JavaScript como parte del módulo de **Desarrollo Avanzado de JavaScript de DEV.F**.

## 📌 Descripción

Aplicación web que consume la API pública de Rick and Morty utilizando **Fetch y Axios** para obtener información de los personajes y mostrarla dinámicamente en una página web.

## ⚙️ Funcionalidades

- Consultar personajes mediante Fetch.
- Consultar personajes mediante Axios.
- Mostrar imágenes, nombres, estados y especies de los personajes.
- Generar tarjetas dinámicamente utilizando el DOM.
- Manejar posibles errores en las solicitudes HTTP.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Fetch API
- Axios
- Rick and Morty API

## 📚 Conceptos practicados

- Consumo de APIs REST.
- Solicitudes HTTP con el método GET.
- Programación asíncrona con `async/await`.
- Manejo de errores con `try/catch`.
- Manipulación del DOM.
- Procesamiento de datos JSON.

## 🎯 Objetivo

Comprender el funcionamiento de las solicitudes HTTP y comparar el uso de Fetch y Axios para consumir información de una API externa y representarla dinámicamente en una interfaz web.

**API utilizada:** https://rickandmortyapi.com/
